# Análisis de ventas y rentabilidad con Python

## Descripción del proyecto

Este proyecto analiza datos comerciales para identificar tendencias de ventas, evaluar la rentabilidad y detectar oportunidades de mejora mediante Python.

El análisis se realiza utilizando el conjunto de datos Sample Superstore.

## Objetivos

- Analizar la evolución anual de las ventas y los beneficios.
- Comparar la rentabilidad entre categorías y subcategorías.
- Investigar la relación entre los descuentos y los beneficios.
- Identificar productos con mayores pérdidas acumuladas.
- Proponer recomendaciones comerciales basadas en los resultados.

## Herramientas utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## Principales hallazgos

- Las ventas alcanzaron su valor máximo en 2017.
- Technology obtuvo el mayor beneficio total entre las categorías.
- Furniture presentó un margen de beneficio considerablemente inferior al de las otras categorías.
- Tables, Bookcases y Supplies registraron beneficios acumulados negativos.
- Los descuentos elevados aparecieron asociados con beneficios promedio negativos en varios grupos.
- Los diez productos con mayores pérdidas acumularon un resultado de -29.458,37.

## Metodología

1. Carga y exploración de los datos.
2. Revisión de calidad y conversión de fechas.
3. Análisis temporal de ventas y beneficios.
4. Comparación de rentabilidad por categoría y subcategoría.
5. Análisis de descuentos.
6. Identificación de productos con mayores pérdidas.
7. Elaboración de conclusiones y recomendaciones.

## Conclusión

El análisis muestra que el crecimiento de las ventas no garantiza una mejora continua del margen de beneficio. Por ello, resulta importante evaluar conjuntamente las ventas, los beneficios, las categorías de productos y las condiciones comerciales.

## Limitaciones

Los resultados son descriptivos y muestran asociaciones, no necesariamente relaciones causales. Algunos grupos de descuentos contienen pocas observaciones y deben interpretarse con cautela.
